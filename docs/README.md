# SoundHub 기획 문서

버전별 기능명세서를 관리합니다. 폴더 이름은 `build.gradle`의 `version`과 맞춥니다.

## 버전 목록

| 버전 | 주요 내용 | 문서 |
|---|---|---|
| v0.0.1 | 이메일/비밀번호 인증, MVP 1(운영자 백오피스)·MVP 2(사용자 웹 화면) 기능 정의 | [v0.0.1](v0.0.1/README.md) |
| v0.0.2 | 휴대폰 SMS 인증 도입, 회원가입에 휴대폰 인증 필수화, 닉네임 중복 확인 API 제거 | [v0.0.2](v0.0.2/README.md) |

## 작성 규칙

- 기능 하나에 파일 하나를 만들고, 파일 이름은 `도메인-기능.md`로 짓습니다.
- 새 버전 폴더에는 **추가되거나 바뀐 기능만** 작성합니다. 바뀌지 않은 기능은 이전 버전 문서를 그대로 따릅니다.
- 요구사항에는 `도메인-번호-세부번호` 형식의 ID를 붙입니다. (예: `AUTH-001-1`) 같은 기능이 다음 버전에서 바뀌어도 ID는 유지합니다.
- 인수 조건은 Given/When/Then으로 작성하고, 성공/실패 테스트 케이스와 1:1로 대응시킵니다.
- 새 문서는 [templates/feature-spec.md](templates/feature-spec.md)를 복사해서 시작합니다.
